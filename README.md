# 🎯 Pitch — Interactive Pitch Decks & Academic Presentation Engine

A streamlined web-based presentation platform for hosting interactive startup pitch decks, academic research summaries, and institutional slide presentations.

## 🚀 Overview
- **Interactive Slide Navigation**: Web-native slide deck experience with seamless keyboard and touch navigation.
- **Academic & Startup Themes**: Pre-configured slide templates for research defenses, startup elevator pitches, and grant proposals.
- **Standalone Web Deployment**: Zero external dependencies, self-hosted via GitHub Pages.

## 🛠️ Technology
- **HTML5 & CSS3 Flexbox/Grid**: Modular slide components and high-resolution typography.
- **Vanilla JavaScript**: State-driven slide transitions, fullscreen toggle, and presenter mode.
